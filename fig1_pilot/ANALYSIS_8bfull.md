## 结论(2026-07-28 聚合后判读)

1. **成本下降曲线在"近重复档"最干净**:mem 从首集 3445 tok 降到末三集约 2000,nomem 全程平在 ~3600——第 7 集起 mem 比 nomem 便宜 ~40%。这就是主轴一号图(成本随经验下降)在真实 agent 任务上的第一份实证。
2. **完全重复档暴露记忆饥饿**:nomem 逐集完全相同(贪心+同 trial=确定性重放,6874 平线),mem 只省 12%,成功率纹丝不动 0.60——只存成功经验的记忆救不了模型本来就做不成的 40% 任务,重复失败不产生可复用经验。
3. **部分相似档的真账是"输入税"**:mem 的输出 token 只省 5%,但输入 token 贵 42%(记忆内容全贴进提示);算总 token 反而 +20%。墙钟仍 −7%,因为输入是预填充、比逐 token 解码便宜——**记忆的本质交易是拿便宜的输入 token 换昂贵的输出 token**,论文记账必须输入输出分开列,否则就是在藏成本。
4. **8B 的红利比 4B 小**(−12% vs 先导 4B 的 −31%):模型越强,裸跑越不吃亏,天然记忆的边际收益缩水——这给"要学习型投机器而不是裸贴记忆"又添一条论据。
5. 成功率三档全部 mem=nomem(聚合层面):ALFWorld 这批任务对 8B 太软,准确率维度无信息量,汇率曲线的准确率侧要靠更难的任务源(τ-bench/多跳)补。
