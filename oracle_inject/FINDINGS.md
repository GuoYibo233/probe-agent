## 四个结构性发现

1. **省 token 曲线非单调，存在"决策区死区"**：开场注入 ≫ 提前100–200 ≫ 0 ≈ 不注 > **提前25–50（负收益，acc 还降 5–15pp）**。
   模型在决策中段被打断会重新纠结。⚠️ 对探针路线的警报：置信度高了才注 ≈ 贴近调用点 ≈ 落进死区；
   大头收益在"很早注入"= 记忆/预取来源（来源二），不是贴近调用的内部信号触发（来源一）。
2. **授权措辞是承重墙**（无授权消融，Qwen3.5-4B）：开场注入 -1056 tok / acc 0.00（复读脱轨，同 smoke3 现象）；
   中段注入模型守协议照样调用，收益归零。→ 设计空间第 1 层"措辞打预防针"从灵感升级为实测必要条件。
3. **授权 ⇒ 轻信**：错误注入 acc 崩到 0.02–0.14（所有授权模型）。无授权时协议复验曾天然免毒（smoke4 实测）。
   → "接受但不轻信"训练目标的必要性被量化。信任是个旋钮，两端都有代价。
4. **模型差异**：1.7B 不思考直接调用（无"想"可偷，投机只剩"等"可藏）；Qwen3.5-9B 在此 prompt 下 55/60 拒走协议
   （宁可瞎猜也不调用），信号=协议遵守本身对 prompt/模型极敏感，放大实验需按模型调 prompt 或换真实工具环境。

## 诚实边界

- 合成单跳 lookup，思考长度 100–255 tok ⇒ 省的绝对量是秒级不是分钟级；多跳/真实 agent 任务待测。
- "省 token"含我们代回的 RESULT 行 token（约 +20/次调用），对比方向一致，绝对值有小偏差。
- 贪心解码单次采样；未做温度/多次采样方差。
- 9B 的注入数据 n=5 不可用；1.7B 无可省空间。结论主要立在 3.5-4B / 3-4B / 3-8B 三点上。
