## 0. 先钉死阶梯命名(发现一处项目内冲突,必须现在解决)

项目里同时存在两套 L 编号,方向相反:

| 语义 | fig1_run.py 代码标签 | TraceLab 写法 / 本稿正典 |

## 1. L3:组合相似

### 1.1 操作性定义

把每个任务分解成一个带类型的成分元组;ALFWorld 是 $(\text{模板}, \text{物体}, \text{容器}, \text{场景})$,HotpotQA/2wiki 是跳链 $\langle(e_1, r_1), (e_2, r_2), \dots\rangle$(实体、关系,各带 gold 文档)。

**L3 任务 = 每个成分都在种子集历史中单独出现过、但该成分组合从未出现过的任务。**

批量生成流程(从种子集 $S$ 出发,全自动):

1. 对 $S$ 中每个任务抽成分元组,建成分清单(每维一个已见值集合)。
2. 在各维已见值的笛卡尔积上采样候选,剔除与 $S$ 中任一任务元组相等的组合。
3. 可行性过滤:ALFWorld 按 game 文件路径枚举(组合存在即有对应 trial 目录,任务空间本身可枚举);Hotpot/2wiki 要求拼接点实体一致且目标关系在 gold 三元组中有出处——**2wiki 自带 (subject, relation, object) 证据三元组,组合可编程验证,这是选它做 L3 主域的决定性理由**。
4. 每个 L3 项记录其"零件出处"(来自哪几个种子任务),读数分析时按零件数分层。

### 1.2 ALFWorld 三例

种子集已含:pick_and_place_simple(Apple, Fridge)、pick_and_place_simple(Mug, Desk)、pick_cool_then_place(Tomato, DiningTable)。

1. **跨任务零件重组**:pick_and_place_simple(Apple, **Desk**)——物体来自种子一,容器来自种子二,组合是新的。考"找 Apple 的搜索路线"和"放 Desk 的收尾动作"能否拼起来用。
2. **技能移植**:pick_cool_then_place(**Apple**, DiningTable)——"冷却→放置"流程来自种子三,Apple 的位置先验来自种子一。考流程记忆是否绑死在原物体上。
3. **数量升级**:pick_two_obj_and_place(Apple, Fridge)——单物体流程完整见过,双份是新的。考记忆是"整条轨迹"还是"可循环调用的子程序"。

### 1.3 HotpotQA/2wiki 三例

种子集已含:Q1 "电影 $F$ 的导演是谁"(答 $D$,gold 文档 $\mathrm{doc}_F$)、Q2 "$D$ 生于哪一年"(gold 文档 $\mathrm{doc}_D$)、Q3 comparison "$A$ 和 $B$ 谁先成立"。

1. **两跳拼接**:"电影 $F$ 的导演生于哪一年"——hop1 来自 Q1、hop2 来自 Q2,拼接点 $D$ 一致,两份 gold 文档都在记忆里,链是新的。这是投机器参数头的理想考场:hop2 参数($D$)在记忆里可查。
2. **比较对重配**:comparison"$A$ 和 $C$ 谁先成立"——实体 $A$、属性"成立年份"都见过($C$ 来自另一道见过的 comparison),配对是新的。
3. **三跳延长**:种子含 bridge $E_1 \to E_2$ 与 bridge $E_2 \to E_3$,L3 = "从 $E_1$ 出发问 $E_3$ 的属性"——两条见过的两跳链首尾相接成三跳,全部证据已在记忆中。

### 1.4 L3 的读数含义

L3 分离两种记忆:死记轨迹的记忆在 L3 上拿不到加速(组合没见过,整条检索不中),组件化的记忆拿得到部分加速且准确率不掉。**L3 加速比落在 L2 与 L0 之间的哪个位置,直接量化被试记忆的组合泛化能力**——这是 Evo-Memory 系动物园被试之间真正拉开差距的档位。

## 2. L4:假相似(诱导错误迁移)

### 2.1 操作性定义

固定一个最小编辑族 $E$(见 2.2/2.3 的六类)。对种子任务 $x$(其存储解为 $\pi^*$)施加编辑 $\varepsilon \in E$ 得 $x'$,收录为 L4 当且仅当同时满足:

1. **表面相似达标**:$\mathrm{sim}(x', x) \ge \tau$,$\tau$ 取该域 L2 重复对相似度分布的 p50——L4 对在检索器眼里和重复一样像。相似度用任务指令(+首帧观察)的 embedding 余弦,仪器写死并在论文声明(TraceLab 只能测工具构成相似,这个边界如实标注)。
2. **旧解回放必败**:把 $\pi^*$ 机械回放到 $x'$ 上,最终判分必须失败。**这是陷阱有效性检查,逐条机械执行,不通过不收录**——保证 L4 的负迁移读数不掺"其实旧解也能对付"的假阴性。

**一句话:L4 任务 = 与某已见任务的表面相似度不低于重复档、且旧解经回放验证必然失败的最小编辑变体。**

批量生成 = 种子 × 编辑族笛卡尔积 → 双过滤。TraceLab 实测 10.8% 高相似对跨 project,说明这不是人造攻击而是真实负载里的常态,论文里 L4 段落用这个数开头。

### 2.2 ALFWorld 三例(三类编辑)

1. **位置改换**(编辑=换 trial):同一条指令 "put the apple in the fridge",选 Apple 初始位置不同的另一 trial(原在台面,现在微波炉里)。指令逐字相同,记忆里的搜索路线全部扑空。ALFWorld 同模板 trial 天然位置各异,这类对不用改引擎、成对枚举即可。
2. **动词翻转**(编辑=换模板一词):种子 pick_heat_then_place(Egg, GarbageCan),L4 = pick_**cool**_then_place(Egg, GarbageCan)。指令只差一个词,轨迹 90% 重合,但复用旧解(进微波炉)判分必败。
3. **数量翻转**(编辑=单↔双):种子 pick_and_place_simple(Apple, Fridge),L4 = pick_two_obj_and_place(Apple, Fridge),指令只多一个 "two"。复制单物体旧解会在放入一个后提前收工,静默失败。

### 2.3 HotpotQA/2wiki 三例(三类编辑)

1. **极性翻转**:种子 "谁生得**更早**,$A$ 还是 $B$"(答 $A$),L4 = "谁生得**更晚**"。证据文档完全相同,答案确定性反转。复述记忆答案 = 精确答错。
2. **易混实体替换**:把种子里的 $X$ 换成同关系、同姓氏/同名系的 $X'$(用 2wiki 三元组按 relation 相同、subject 不同自动挑),记忆里 $X$ 的文档对 $X'$ 全部失效。这是 TraceLab 跨 project 假相似的直接实验室版。
3. **锚点角色改换**:种子 "电影 $F$ 的**导演**得过什么奖",L4 = "电影 $F$ 的**作曲**得过什么奖"。hop1 文档($\mathrm{doc}_F$)相同,hop2 目标不同——按旧解预取导演页面是精确的错误预取,直接考投机器。

### 2.4 陷阱强度分级(自动定级,不靠人标)

强度由回放的**分歧深度**定:回放 $\pi^*$ 于 $x'$,记 $d^* \in [0,1]$ 为首次出现矛盾信号(环境报错 / 观察与预期不符 / 检索文档不含目标实体)时已执行的轨迹比例。

| 档 | 判据 | 含义 | 上面例子 |
|---|---|---|---|
| T1 弱 | $d^* < 0.25$ | 开局即穿帮,纠错便宜 | 易混实体替换(文档里没这个名字) |
| T2 中 | $0.25 \le d^* < 1$ | 前缀白走,中途穿帮 | 位置改换、锚点角色改换(hop1 顺利 hop2 才错) |
| T3 强 | 回放走完无任何矛盾信号,仅终局判分失败 | 静默错误,过程零警报 | 极性翻转、数量翻转 |

T3 是最危险档有实测背书:错误文档注入照样"省" +319 token 而 soft acc −34pp(hotpot 第二波)——错得快和对得快在过程指标上不可区分,只有终局判分见分晓。发布版 L4 按 T1:T2:T3 配平,并在元数据里带档位标签。

### 2.5 负迁移怎么从 L4 读数

**探针流设计**:流 = 前段 seeding(L2 档任务,保证记忆装载,要求成功数下限,不达标的 run 整条作废)+ 后段 L4 探针段。探针段冻结记忆写入、只读检索(在线更新版本是第 17 步消融的事,测量段必须冻结)。nomem 对照臂走**同一条流**(含 seeding 段),只是不写记忆——保证位置与上下文长度对齐。四个读出,只在探针段、ok-only 配对格上算:

1. **准确率负迁移** $\mathrm{NTI}_{acc}$(定义见 3.4):正值即记忆使人答错。
2. **成本负迁移** $\mathrm{NTI}_{cost}$:记忆使人更慢(误检索+纠错)或更快但错(T3 特征)。两个数必须并排报,单报任何一个都会漏掉一半失败模式。
3. **误迁移率** $\mathrm{MTR}$ = 探针集里"行为前缀复制旧解超过分歧点 $d^*$"的比例——这是机制读数,证明掉分确实来自照抄而非任务变难(nomem 臂在同一任务上的表现就是"任务本身难度"的对照)。
4. **投机器专用:错误预取率** = 投机头发出的调用中,与旧解调用匹配、与正确调用不匹配的比例(第 18 步接这里)。

主图读法:横轴 T1→T3 陷阱强度,纵轴四个读出——**剂量-响应曲线**。好的记忆系统应该 T1 免疫(便宜信号足以刹车)、T3 才掉;差的系统 T1 就掉。这一张图把"抵抗误用的能力"排出被试座次。

## 3. 指标形式化(第 11 步)

### 3.1 记号

- 档位 $\ell \in \{L0,\dots,L4\}$;每档一条长度 $K$ 的任务流;run $r$ = (种子任务流实例, 随机种子),两臂 mem / nomem 跑同一 $r$。
- $u_{r,k} \in [0,1]$:第 $k$ 集成绩(ALFWorld 成功 0/1;QA 用 soft acc)。$c_{r,k} > 0$:第 $k$ 集成本,**正典货币 = tok_in + tok_out**;墙钟只在同硬件内报(redo106 教训:A6000 与 H200 墙钟不可比,token 是唯一跨机可比货币)。
- 每集带三态 $\mathrm{status} \in \{\mathrm{ok}, \mathrm{degen}, \mathrm{forced}\}$(hotpot 协议),主指标一律 ok-only。
- **配对格** $P_k$ = 两臂在 $(r,k)$ 上均为 ok 且两臂 run 均完整跑满 $K$ 集的 run 集合。所有比较都在 $P_k$ 上做。

### 3.2 Speedup@k

$$\mathrm{Sp}@k \;=\; 1 - \frac{\sum_{r \in P_k} c^{\mathrm{mem}}_{r,k}}{\sum_{r \in P_k} c^{\mathrm{nomem}}_{r,k}}$$

- 分母是 nomem 地板在同集位、同任务实例、同种子上的成本——配对到地板而不是配对到自己第 1 集,因为流内任务难度随位置起伏,地板臂把难度项消掉了(L1 流还特意 shuffle 过位置)。
- 用**和的比**而不是逐 run 比值的均值:hotpot 实测省 token 分布重尾(中位数近零、均值深负),逐 run 比值会被小分母炸飞;和的比等价于 token 加权,稳。区间估计用对 run 的 bootstrap。
- 边界:$|P_k| < m$(门槛,建议 $m=4$)则该点**不报告**,画图留缺口,不许用幸存 run 顶上;$\mathrm{Sp}@k$ **永远与同一 $P_k$ 上的 $\mathrm{Acc}@k = \frac{1}{|P_k|}\sum_r u^{\mathrm{mem}}_{r,k}$ 并排出现**——错得快也能刷高 Speedup(错注 +319 token 的教训),单独出现即无效。

### 3.3 cost-to-competence

滑窗能力 $\hat p_{r,k} = \frac{1}{w}\sum_{j=k-w+1}^{k} u_{r,j}$(窗宽 $w=3$),达标集位 $k^*_r(\theta) = \min\{k \ge w : \hat p_{r,k} \ge \theta\}$,不存在则记 $k^*_r = \infty$(censored)。

$$\mathrm{CTC}_r(\theta) \;=\; \sum_{j=1}^{\min(k^*_r,\,K)} c_{r,j}$$

- 累计成本**包含失败集**——学费本来就含挂科重修,这正是该指标与终点准确率的区别。
- **边界(核心规则)**:未达标 run 的 $\mathrm{CTC}_r$ 记全流预算 $\sum_{j=1}^{K} c_{r,j}$ 并标 censored,报告值带 $\ge$ 号;同时必报**达标率** $\rho(\theta) = |\{r : k^*_r \le K\}| / |R|$。**禁止只在达标 run 上取均值**——那是幸存者偏差的教科书形态。汇总统计用中位数(对 censored 值稳健)。
- $\theta$ 取双轨:绝对档 $\theta \in \{0.5, 0.7\}$ + 相对档 $\theta = $ nomem 全流均值 $+\,10\mathrm{pp}$(保证跨域可比:难域绝对档可能全员 censored)。

### 3.4 负迁移指数

在 L4 探针段 $Q$(见 2.5,seeding 段一律剔除)、ok-only 配对格上:

$$\mathrm{NTI}_{acc} \;=\; \bar u^{\mathrm{nomem}}_Q - \bar u^{\mathrm{mem}}_Q, \qquad \mathrm{NTI}_{cost} \;=\; \frac{\bar c^{\mathrm{mem}}_Q - \bar c^{\mathrm{nomem}}_Q}{\bar c^{\mathrm{nomem}}_Q}$$

- 两个都是**正值 = 负迁移**。保留符号不截断:负值(记忆在陷阱上居然还赚)本身是重要读数。
- 不合成单标量:$\mathrm{NTI}_{acc} > 0,\ \mathrm{NTI}_{cost} < 0$(更快但错,T3 特征)与 $\mathrm{NTI}_{acc} > 0,\ \mathrm{NTI}_{cost} > 0$(又慢又错,T2 特征)是两种病,加权和会把它们抹平。报二维点 + 按 T1/T2/T3 分层。
- 机制佐证挂 $\mathrm{MTR}$(2.5 第 3 条):$\mathrm{NTI}_{acc}$ 显著但 $\mathrm{MTR} \approx 0$ 说明掉分另有原因(如上下文膨胀),不许写成"经验误用"。
- 边界:seeding 成功数不达门槛的 run 整条作废(记忆没装上,NTI 无定义);$Q$ 内每档 T1/T2/T3 至少 $n \ge 10$ 条否则该档不单独报。
- 对照读数:同一被试在 L0 无关流上的 $\Delta(\ell) = \bar u^{\mathrm{mem}} - \bar u^{\mathrm{nomem}}$ 应 $\approx 0$(检索不中就不该有影响);L0 上也掉分说明是记忆机制的无差别开销,与 L4 的靶向误用要在论文里分开归因。

### 3.5 防幸存者偏差聚合规则(全指标通用)

第一波的事故:07-25 晚不完整矩阵上取逐集均值,快种子先完赛,慢种子还没进表,"L0 −63%"与"准确率不涨"全是偏差产物,已作废。规则五条,写进分析脚本不靠自觉:

1. **完整格规则**:任何逐集曲线只用跑满 $K$ 集的 run;部分 run 不得进集位均值(analyze_full.py 的 `min_eps` 门已实现,保持)。
2. **配对差分规则**:一切 mem−nomem 比较在 (run, 集位, 任务实例) 三对齐的格上做,任一臂缺格则整格弃用。
3. **三态审计规则**:主指标 ok-only,但各条件的 ok 率本身必报——某条件靠打掉难例刷 ok-only 均值,ok 率会出卖它。
4. **Censoring 显式规则**:CTC 未达标记全预算带 $\ge$,配达标率;禁止 reachers-only 均值。
5. **硬件分层规则**:墙钟不跨硬件汇总;跨机比较只用 token。
