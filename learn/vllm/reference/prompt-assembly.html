raw 模式：反过来，拼在我们这边

两条链的边界正好是反的。chat 模式我们交出去的是四条消息，最终 prompt 里有一整段（模型身份、当天日期、频道说明）我们从没写过；raw 模式最终 prompt 里每个字符都是我们敲的。--api 这一个开关，换的不是格式，是"谁来决定模型看到什么"。

哪一格是不确定的

上图第 8 步里 Current date 那一行取自 datetime.datetime.now()。vLLM 自己在 harmony_utils.py:134 那儿留了一句注释：

# NOTE(woosuk): This brings non-determinism in vLLM.
# Set VLLM_SYSTEM_START_DATE to pin it.

发射脚本 launch_vllm_awdiag.py 没设 VLLM_SYSTEM_START_DATE。所以跨天重跑同一个任务，prompt 的第 3 行会变一个字，前面的 token 全都对不上——这是整条链里唯一一格我们的代码管不着的内容。
