temperature 的分界线

temperature < 1e-5 → 贪心档

sampling_params.py:27, 492-497：低于这个界，top_p／top_k／min_p 一并被覆盖成不筛选，走 logits.argmax（v1/sample/sampler.py:240-241）。seed 在这条路上不起作用。

报数字时该带上的口径

  1. token 数是"发过去的"还是"重算的"——默认只拿得到前者。
  2. 并发是多少——它会改批组成，进而改 greedy 生成的结果。
  3. 有没有中途中止——中止的段落 usage 缺失，token 数是估的。
  4. 被丢弃的生成单独一列——算力花过，不该并进"省下的"。
