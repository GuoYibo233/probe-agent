## 要求

### 分发器 ledger.py

- argparse 子命令注册 plan.md §C2 的**全部**子命令名（含还没实现的），每个
  子命令 lazy import `ledger_cmds.<模块>`；模块缺失或没有对应函数 →
  stderr `not implemented yet: <subcommand>`，exit 3。
- 模块协议：每个模块暴露 `register(subparsers)`（自己加参数）与
  `run(args) -> int`。分发器 try import，ImportError 时用占位 parser
  （接受任意参数）保证 exit 3 路径可达。
- 工程门禁：除 `gen-schemas`、`init`、`config-check` 外，dispatch 前
  `find_project_root()`；None → stderr
  `project not wired: research-loop.json not found (run: ledger.py init)`，exit 2。
- `RLError` 统一在 main 捕获：stderr 打 message，exit 2。其他异常照常抛
  （不吞栈）。

### gen-schemas（ledger_cmds/genschemas.py）

按 plan.md §C4 实现：八块→八文件 + `owners.default.json`，序列化
`json.dumps(x, indent=2, sort_keys=True, ensure_ascii=False) + "\n"`。变换规则：

- `$enum: <name>` → `{"enum": tables.rows.enums[<name>]}`（名字查无 → RLError）。
- `$ref_to` 原样保留；`type`/`const`/`minimum`/`items`（items 内部同样做
  `$enum` 展开）照搬；`_note` 及一切 `_` 开头键丢弃（`_doc_keys`）。
- 顶层：`$comment` 固定串
  `"generated by ledger.py gen-schemas from tables/rows.json -- DO NOT EDIT"`、
  `ledger`（块对应账名，映射抄 plan.md §C4）、`primary_key`、`type: "object"`、
  `required`、`additionalProperties`、`properties`、`conditional`
  （conditional 里的 `_note` 也删）。
- `owners.default.json`：`tables/ledgers.json` 主表（不含 optional_ledgers）的
  `{账名: owner}`。
- `--check`：内存重生成，逐字节比对 9 个文件；不一致列文件名，exit 1，
  **不写盘**；文件缺失算不一致。
