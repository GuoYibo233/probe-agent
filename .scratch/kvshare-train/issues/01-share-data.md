## What to do

Create `pipeline/train/share_data.py`, holding only pure CPU logic (tokenizer and python data structures, no importing of any model), shared by the trainer in ticket 03 and by ctool and `eval_tool.py` in ticket 02. **The module top level may only import stdlib and torch**: the imports of the two old training scripts must be written inside the body of `load_events` (reason per spec 3.3: the old scripts have a transformers >= 5.14 version gate at module level, which raises `SystemExit` on import under mbert-env, and `eval_tool.py` needs to import this module under mbert-env to get `read_position`).

1. `load_events(path, tok, mode, max_len, ro=None, limit=0, order="random")`: each step's order is fixed exactly as in spec 3.2 (group -> prefix spot-check -> full-text tokenization and event-level dropping -> take a subset by `limit`/`order` -> per-row tokenization and row-level dropping only on the events left). Take rows and target strings per 3.3 (inside the function body, `import` `CALL_SEP / MAX_TGT_TOK / SEED` from `train_causal_callgen` and `param_prompt_tail / param_target` from `train_causal_param`; do not copy them). Keep both hard stops as-is. Compute `p / seg_ids / seg_lab` for each row per 3.4, then assert the packed-length upper bound from spec 3.5 (import `MAX_BOUNDS` from `pipeline/annotate/rules.py`, also inside the function body). Return a list of events (each event holds `event, n_full, packed_len, prefix_len P, rows=[(sent_idx, text, p, seg_ids, seg_lab, w)]`; event order = order of first appearance in the file, row order = ascending `sent_idx`; both orderings are a contract that the alignment check relies on for positional pairing) and a count dict (`dropped_events, dropped_rows_tgt, assembly_mismatch, n_rows`). When `limit > 0`, take the first `limit` events per `order`: `"random"` = build a fresh `random.Random(SEED)` (not the generator used for the prefix spot-check; spec 3.2), shuffle, then take the first `limit`; `"shortest"` = take the first `limit` events by ascending `n_full` (used by `--smoke` in spec section 8). Also provide `worst_blocks(events, tok_budget, events_per_mb)`, returning two event lists: "the single event with the largest `packed_len`"; "the fullest block" = for B from 2 to `events_per_mb`, scan events in descending `packed_len` order and take the longest run of B events with `B x L_pad <= tok_budget` (`L_pad` = the longest `packed_len` in the block padded up to a multiple of 16), then take whichever B gives the largest `B x L_pad` (spec section 10). `chunk_by_budget`'s budget test uses the same `L_pad` (spec section 5).
2. `pack_event(ev)`: returns one event's packed sequence `tokens, positions, labels, row_index` (which row each token belongs to; the prefix is -1) and `seg_bounds` (each segment's start/end in the packed sequence), per spec section 4.
3. `allowed_mask(ev)` and `batch_mask(packed_list, L_pad)`: the former returns one event's `[L, L]` bool tensor (True = visible, per the relation in spec section 4); the latter right-pads several events of a physical block to `L_pad` (a multiple of 16) and builds the `[B, 1, L_pad, L_pad]` bf16 additive mask (0 = visible, -inf = not visible; a pad row acting as a query may only see itself), `position_ids`, `input_ids`, and the loss-position index table `(batch_idx, qpos, target_id, row_idx)`.
4. `chunk_by_budget(events, tok_budget)`: the greedy packing from spec section 5, second clause; returns a list of blocks, each block a list of events; a single event over budget becomes its own block.
5. `read_position(offsets, full_text, cut, keep)`: the read-position rule from spec 11.3. Input is the tokenizer's `offset_mapping` list, the full text, the cut point's character position, and the real token count `keep`; search only within `offsets[:keep]`; return -1 when not found (no real token's start position is < cut, or the rule needs to fall back to j-1 while j = 0).
6. Tests `tests/test_share_data.py`, covering (a) through (e) of spec 12. The real-tokenizer path uses the old scripts' `MODELS["qwen"]` (the test must also import the old scripts lazily, catching both `ImportError` and `SystemExit` as skip, per `tests/test_cparam_assembly.py` lines 21-29); skip if it doesn't exist. The val set path is `pipeline/data/nyapass_aw_v1/gptoss/val.jsonl`; skip if it doesn't exist either.
