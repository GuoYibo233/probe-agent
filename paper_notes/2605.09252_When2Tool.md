# When2Tool: LLM Agents Already Know When to Call Tools — Even Without Reasoning

- arXiv 2605.09252（v2, 2026-05-20；v1 2026-05-10）· Sun / Liu / Yan / Wang / Weng — UC San Diego（venue 文中未见，预印本）· 开源 github.com/Trustworthy-ML-Lab/when2tool

- 读于 2026-07-20

## TAMMIC

- **Motivation**: agent 不分青红皂白地调工具，白烧 API 费和延迟；没有 benchmark 系统研究"这次调用有没有必要"，更没人追问乱调的根源是**不知道**还是**知道却做不到**。
- **Method**: When2Tool 基准（18 个环境 = 15 个单跳 + 3 个多跳；3 类必要性：算力 A / 知识 B / 执行 C；3 档难度，边界落在 medium）→ 证明 Prompt-only 和 Reason-then-Act 都控不住 → 线性探针（末 token 全层隐藏态 + L2 逻辑回归，CPU 几秒）读生成前表征 → Probe&Prefill：p 与 τ 比较后往回复开头预填开场白。
- **Insight**: 六个模型的 AUROC 达到 0.89–0.96，远超模型口头自评；Llama 推理彻底崩溃（70B 83.1%→47.9%，声明调用但写不出合法格式）时隐藏状态信号依然完好，知识独立于表达。显式推理对工具必要性判断"largely superficial"。
- **Contribution**: 构建基准 + 探针诊断，发现模型内部早就知道何时需要工具、只是生成时不照做；"探针 + 预填开场白"减 48% 调用只损 1.7% 准确率（最佳 baseline 同准确率只减 6%）。

## 关键机制

- **标签定义（全文最关键假设）**：无工具强答答对 = tool-unnecessary。必要性被操作化成"该模型自己做不做得对"，模型相关、探针按模型各训一个，且混入采样成败噪声（文中未讨论）。
- **零额外开销**：末 token 隐藏态是 prompt 编码前向（拿 KV cache）的副产品；探针 <1ms（附录 F），无额外前向、无额外模型调用。
- **软/硬 prefill**：软的给建议句、模型可反悔；Llama 指令跟随差会无视软 prefill，需硬 prefill 强制输出格式（\boxed{ 或工具 JSON），代价是探针错判时无兜底。
- **τ 是唯一旋钮**：扫 0.1–0.9 得平滑取舍曲线；提示工程只有几个离散不可插值的工作点。
- **选择性省调用**（Table 4 关键结论）：hard 档 ΔTC 仅 −0.24（少砍该调的）、easy 档 −0.66（多砍不该调的），砍的位置是对的。

## KURR

- **Keyword**: linear probing LLM · tool-call decision · self-knowledge calibration · prefill steering · Search-o1 · agentic efficiency
- **Unknown（作者自认）**: 软 prefill 被 Llama 无视需硬 prefill；Reason-then-Act 失败的病理只有现象描述。
- **Unknown（我看出的）**: 标签混采样噪声未讨论；探针跨模型迁移未探索（附录 D 只做跨环境）；开放域多工具下"线性可解码"是否成立未知；多轮对话中途隐藏状态被历史污染时是否有效未明说。
- **我赢它在哪**（对标笔记，router 路线最强外部证据）: 它证明了"隐藏状态里有工具决策信号、线性探针读得出、prefill 接得上输出端"，整条 router 路线的可行性由它背书。但它只做**二分类**（调不调），且只在**生成前**读一次末 token；我的 router 做四个头（调不调/调什么/参数/输出）粒度全面升级，且逐 token 连续读、可在 CoT 进行中提前投机执行。它的"reasoning largely superficial"发现反过来支持我的方案：既然口头推理不增加信息，投机执行就不必等推理写完。注意防守点：它已占住"探针读工具决策"的 novelty，我必须把 delta 讲成"从判别到投机执行的闭环 + 参数/输出生成"，不能只说"我也用探针"。
