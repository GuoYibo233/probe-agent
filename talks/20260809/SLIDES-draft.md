# 组会幻灯片逐页草稿（17 页版）

每页三行信息：一句话概括、页面元素（图/表/bullet）、数字出处。
数字出处都在 `data/` 各文件里。

## 背景（页 1 到 5）

### 页 1 标题页
- 一句话：探针提前预测 agent 的工具调用——一项进行到一半的研究。
- 元素：标题 + 姓名日期 + 一行副标题（比如"训练一个小探针，在模型想到一半时
  预测它接下来要调什么工具"）。

### 页 2 agent 与 tool call 是什么（合并页）
- 一句话：agent 每一步是"想一段、调个工具、看结果、接着想"的循环。
- 元素：
  - 图：循环示意（思考 → 工具调用 → 环境结果 → 回到思考），四个框一个环。
  - 例子框：一步真实轨迹截段——思考文本节选（掐头留尾）+ 末尾那条真实调用
    （如 `apis.supervisor.show_profile(...)`），思考部分打省略号显长度。
  - 例子从 hcap 轨迹（现役 RESULTS 唯一 run）或旧轨迹里截。

### 页 3 思考很贵
- 一句话：思考 token 又长又贵，占大头。
- 元素（三个 bullet，可配一个对比条形图）：
  - gptoss 每步思考中位 2991 字符，q36 是 292——差十倍（条形图就画这两根）。
  - AppWorld 168 题跑一遍，单臂计费 token 3.3M 到 5.7M。
  - 思考还会失控：有轨迹单步顶到 8192 生成上限。
- 出处：`data/01-settings.md`、`data/04-live-runs.md`、`data/07-current-phase.md`。

### 页 4 相关工作：ReAct
- 一句话：ReAct 立了"边想边调工具"的 agent 范式，就是页 2 那个循环的出处。
- 元素：论文截图或重画其"推理与动作交替"示意 + 一行引用（Yao et al., 2022,
  arxiv 2210.03629）+ 一个 bullet（推理文字定计划、动作从环境拿信息）。

### 页 5 引出：overthinking 到 agent
- 一句话：chat 场景有人研究防止想太多；agent 场景的独特便宜是——要调哪个
  工具约等于一道选择题。
- 元素：
  - bullet 1：chat/数学场景已有系统研究（Chen et al., 2024, arxiv 2412.21187：
    简单题上大量思考 token 白花）。
  - bullet 2：我把省思考的目标带到 agent 场景。
  - bullet 3（选择题直觉）：AppWorld 全部工具 183 个、ALFWorld 常用动作十来个
    ——下一步调什么是封闭集合上的选择，不是开放生成。
  - 可选小字：选择题也有"瞎蒙分"——ALFWorld 上永远猜 `go` 就对 0.548，
    后面的结果都要对着这条先验线看（给页 13 埋伏笔）。

## 想法（页 6 到 7）

### 页 6 想法的起点：Toolformer
- 一句话：Toolformer 证明"文本中间插入 API 调用和结果"成立；顺着往前一步——
  调用能不能不等模型自己写完，由旁观者提前发出。
- 元素：论文的文本插调用示意（截图或重画）+ 一行引用（Schick et al., 2023,
  arxiv 2302.04761）+ 结尾一个问题 bullet："插入的位置和内容，能不能由
  一个便宜的旁观者提前决定？"

### 页 7 方法核心
- 一句话：训练一个便宜的小探针，读尽量少的思考前缀，提前预测这一步要调的工具。
- 元素：
  - 图（本页是全场主图）：一条思考文本流，句子边界处画切口刻度；探针在旁路
    读"任务 + 历史 + 思考前缀"；置信度过 θ 的切口上标"出手：预测工具名"。
  - bullet 1：探针成本约为 agent 模型的 1/20 到 1/34。
  - bullet 2：读的是重拼文本，不碰 agent 模型内部状态。
  - bullet 3：置信度过阈值 θ 才出手，θ 控制准和早的换算（给页 14 埋伏笔）。
- 出处：`data/02-probe-matrix.md`。

## 做了什么（页 8 到 12）

### 页 8 实验设定总览
- 一句话：两个任务 × 两个执行模型，全部本地 vLLM，按官方题单切分。
- 元素：一张 2×2 格子图（行 AppWorld/ALFWorld，列 gptoss/q36），格里写测试堆
  事件数（2138 / 3150 / 3497 / 2146）；下面两个 bullet：官方题单切分
  （AppWorld train 90 / val 57 / test 168 题），按任务实例切分防泄漏。
- 出处：`data/01-settings.md`。

### 页 9 任务与模型的特点和区别
- 一句话：两个任务一个先验低一个先验高，两个模型思考长度差十倍——正好张开
  四种情形。
- 元素：两张小表。
  - 任务表：AppWorld（手机 app 操作，183 工具，先验 0.16 到 0.40）对
    ALFWorld（文字家务，动作少参数多，`go` 占一半，先验 0.47 到 0.55）。
  - 模型表：gptoss（120B，思考中位 2991 字符）对 q36（27B，思考中位 292 字符）。
- 出处：`data/01-settings.md`。

### 页 10 数据怎么来
- 一句话：agent 做题留轨迹，每个调用步按思考的句子边界切前缀，标签就是这步
  真实调的工具名，全自动零人工。
- 元素：
  - 图：一条轨迹 → 一个调用步 → 思考文本上标出句子边界 → 每个前缀一条样本，
    箭头指向共同标签（这步的真实工具名）。
  - bullet：样本文本 = 任务 + 最近 3 轮历史 + 思考前缀；每事件前缀上限 64 个；
    切分按任务实例。
- 出处：`data/01-settings.md`、`data/08-training-details.md`。

### 页 11 探针怎么训
- 一句话：Qwen3-0.6B 全参微调加一层线性分类头，一个事件整段只前向一次、
  所有句子边界位置同时监督。
- 元素：
  - 图：一条 token 序列，若干位置上标监督点（同一个标签），注"整段一次前向"。
  - bullet 1：位置权重 1/m_i——部署时每个句子边界都会问探针，训练分布对齐
    部署分布。
  - bullet 2：超参一行带过（lr 1e-5、3 epoch、max_len 4096 超长左截保思考尾巴、
    fp32 权重 + bf16 计算、种子写死）。
  - 可选 bullet：对照底座 ModernBERT-base 同流程训练（给页 13 的对照留口）。
- 出处：`data/08-training-details.md`。

### 页 12 θ 怎么定
- 一句话：θ 不是训练产物，是校准产物——拟温度、扫门槛、测试堆冻结报数。
- 元素：
  - 图：数据四堆流程条（训练 70% → 拟温度 10% → 扫门槛 10% → 测试 10%），
    箭头上标每步做什么。
  - bullet：风险档契约——0.1 档触发精度不低于 90%，0.05 档不低于 95%；
    及格线是打赢频率先验。
- 出处：`data/01-settings.md`。

## 结果（页 13 到 15）

### 页 13 主结果：四格单点表
- 一句话：四格触发精度 0.94 到 0.95、全部打过先验，但触发比例随任务差很远
  ——精度和覆盖必须一起读。
- 元素：
  - 表（本页唯一元素，放大）：

    | 任务 | 模型 | θ | 触发比例 | 触发精度 | 先验基线 |
    |---|---|---|---|---|---|
    | AppWorld | q36 | 0.925（0.1 档） | 0.29 | 0.937 | 0.159 |
    | AppWorld | gptoss | 0.975 | 0.30 | 0.951 | 0.404 |
    | ALFWorld | q36 | 0.5 | 1.00 | 0.944 | 0.548 |
    | ALFWorld | gptoss | 0.95 | 0.94 | 0.947 | 0.470 |

  - 表下一行小字：AppWorld q36 行是 0.1 档（0.05 档无解），其余 0.05 档；
    精度分母是"探针敢出手的事件"。
- 出处：`data/02-probe-matrix.md`。

### 页 14 θ 换算曲线
- 一句话：θ 越高猜得越准、出手越少，是一条干净的换算曲线，θ 按风险偏好定。
- 元素：
  - 图：双 y 轴或双线折线图，x 轴 θ（0.5 到 0.95 六点），一条线触发比例
    0.91→0.42，一条线工具名正确率 0.66→0.93（AppWorld × gptoss）。
  - 角注：曲线与页 13 表取点口径不同（曲线 θ=0.95 点 0.925，表里 θ=0.975 点
    0.951），标"另一批评测口径"。
- 出处：`data/03-offline-inject.md` θ 扫描表（只用预测两列）。

### 页 15 提前多少 + 信号在哪
- 一句话：出手时思考远没写完；把思考拿掉精度就崩——信号确实在思考里。
- 元素：
  - bullet 1（提前）：earliness 0.58 到 0.84（数值越大出手越早；ALFWorld q36
    侧 0.836 最早，gptoss 侧 0.58 左右）。
  - 图或双条对比（信号）：消融——去掉思考段，精度从 0.95 档掉到 0.42。
  - 小字：消融批是早期自采分区 + ModernBERT 探针做的，与页 13 的官方分区
    数字是两代场地，只取方向结论不比绝对值。
- 出处：`data/02-probe-matrix.md`。

## 发现与计划（页 16 到 17）

### 页 16 目前的发现
- 一句话：在探针敢出手的那部分事件上（三成到十成，看任务），思考写到早期
  就能以 94% 以上精度预测出工具名。
- 元素：就放这一句话（放大居中），下面三行小字回指证据页：精度与覆盖（页 13）、
  换算曲线（页 14）、提前与信号（页 15）。

### 页 17 未来计划
- 一句话：接下来在三根轴上探索——怎么塞回去、参数怎么来、工具类型分治。
- 元素（三个 bullet）：
  - 怎么把预测结果塞回思考里（塞什么、何时塞的新方案）。
  - 参数怎么来：工具名之外把整条调用补齐（区间抽取 / 工具名钉死参数模型自写）。
  - 工具类型：只读的和会写的分开处理（只读可以大胆抢跑，会写的要谨慎）。
- 口径注意：措辞是"重点探索的轴"，不说"还没做过"（离线注入实验做过，
  这次不讲）。
