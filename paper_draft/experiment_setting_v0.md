# Experiment Setting v0(2026-07-28,三主轴版:test-time learning / 降 cost / 自建 benchmark)

## 1. 主干模型(全程冻结,不训)

- 主模型:Qwen3-8B,贪心解码,thinking 模式。
- 第二尺寸点:Qwen3-4B(同协议全量复跑,量规模效应)。
- Qwen3.5-4B 不当被试,单独报协议脆弱性(基线正常率 40%,48% 自发复读)。
- 工具协议:`CALL: search("...")` / 系统贴 `RESULT:`(逐字回显模型查询串)/ `ANSWER:` 收尾;degen/forced 防护开启,所有脱轨集计入成本不剔除。

## 2. 任务源与任务流

| 任务源 | 用途 | 工具 | 判分 |
|---|---|---|---|
| 合成两跳 lookup | 主学习曲线+陷阱构造(可控) | 查值 | gold 数值解析 |
| HotpotQA fullwiki(comp/bridge 分开) | 真实多跳 | gold 段落缓存检索 + BM25(霰弹枪对照用) | soft 包含判据 |
| 2WikiMultihopQA | 跨数据集复现 | 同上 | soft |
| τ-bench(retail/airline) | 带副作用工具+多工具+方法层复用 | 领域 API,模拟用户=本地小模型 | 数据库终态对比 |

任务流构造(benchmark 本体):
- 每条流 ≥100 集,按相似度档位配比;相似度尺=bge-large-en-v1.5 余弦。
- 档位:3 主线(无关 / 换参数 / 零件重组)+ 2 诊断(原题重复=提速天花板刻度;陷阱=表面相似照搬必错,相似度 0.7–0.95 扫档)。
- 两种配方:真实比例流(高相似 68% / 部分 17% / 无关 15%,取自 TraceLab 357k 轮实测)+ 全新题流(冷启动边界)。
- 每配方 5 个流排列种子。

## 3. 被评系统

**我们的系统(融合版)**:
- 记忆:三层存取(答案/方法/诊断),集末写入,签名=bge 向量;
- 探针:线性头读隐藏态(~31% 深度层,提前量 H=32),输入拼接记忆检索特征(top-1 相似度+其方法模板);
- 参数:三档生产(上下文候选打分复制/零件拼装/草拟验收);
- 准入策略:在线学(信号=模型接受率+token 账单+环境成败),分档门槛(零成本工具全调+塞入侧准入 / 只读收费按置信 / 副作用仅草拟签字后执行);
- 校验梯:字符串归一 → bge 实体比对 → 小模型裁判;复用计划不复用答案。

**基线**:
1. 裸跑(无任何投机);
2. 霰弹枪预取(题面实体抽取+BM25 top-k,k∈{2,4,8},与我们同检索器);
3. 置信度开火(探针 p>τ,τ∈{0.5,0.9,0.99},SPORK 式);
4. 题面文本分类器(不读隐藏态,量隐藏态净贡献);
5. 生实体规则(题面最生实体即查询,参数头对照)。

**消融**(test-time learning 的归因):
a. 全系统;b. 冻结在线更新(热启动后不再学);c. 拆记忆特征(纯探针);d. 拆探针(纯记忆查表);e. 拆校验闸(量闸的疗效)。

**外部被试**(benchmark 公信力):A-Mem、Mem0、AWM、ExpeL(官方码换骨干)+ ExpRAG(自建 50 行);全部先在原设置复出原报告数字再入场。

## 4. 指标与记账规矩

逐集记录:生成 token 数、墙钟、准确率、塞入次数与时刻、错塞标记、工具调用数与(模拟)美元价。

曲线与汇总:
- 主图:每集成本 vs 集数(分档位分系统),随经验下降+消融归因;
- 汇率曲线:激进度从保守扫到激进,每档一点(Δ准确率, Δtoken),连成兑换线;
- Speedup@k、cost-to-competence(达标累计 token)、陷阱档 NTI(负迁移指数)、重复档 pass^k;
- 干扰网格:干扰强度(随机/相似)×篇数(1–16),准确率+账单热图。

防幸存者五条:脱轨集计成本;配对 ok-only 报注入差;n≥15 方进正文;流排列种子≥5;负结果照报(时机头 vs lead 基线)。

## 5. 硬件与实现
