One command to grab the three key lines

grep -E "Using max model len|GPU KV cache size|Maximum concurrency" <log>

To see it together with the memory allocation:

grep -E "Using max model len|Available KV cache memory|GPU KV cache size|\
Maximum concurrency|Free memory on device" <log>

This repo's service logs are at /net/tokyo100-10g/data/str01_01/y-guo/vllm_cache/logs/*srv*.log (batches after 2026-08-01). Earlier batches were at envs/serve_logs/, and have been deleted in cleanup.

One division you must know

Concurrency limit = KV pool capacity ÷ per-request context limit. That N.NNx in the log comes from exactly this, it is not an estimate. After reading the log, do the math by hand once; if it matches, you read the line correctly.
