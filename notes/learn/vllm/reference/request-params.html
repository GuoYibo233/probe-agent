One-sentence rule: if a stop string contains a special token wrapped in angle brackets, you must also pass skip_special_tokens=false, or that string spins with no effect. It does not throw an error.

The methodology to carry when reporting numbers

  1. Token count, whether it is "what was sent" or "recomputed" — by default you only get the former.
  2. Concurrency, how much of it — it changes batch composition, and in turn changes greedy generation results.
  3. Whether there was a mid-run abort — an aborted segment is missing usage, so its token count is estimated.
  4. Discarded generation in its own column — the compute was spent, it should not be folded into "saved."
