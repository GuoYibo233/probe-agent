## 状态书的更新规矩

同一条线第二次出状态书走**更新模式**：新写一份完整的（`exp-status` skill 的产物必须自洽），
旧的那份当天移进 `archive/`，不要两份现役状态书并存——并存就会出现同一个数字两种说法。
